# 项目描述（350 字，含标点与空格）

quantlab 是一个面向中低频策略、分钟/K 线级别的 Python 量化研究工具箱，核心依赖只有 pandas 与 numpy，开箱即跑。它覆盖数据、策略、回测、绩效、模拟实盘全链路：内置合成行情生成器与标准 CSV 加载器，兼容聚宽、掘金等平台导出的数据；内置双均线与 RSI 均值回归策略，同一策略同时提供向量化信号与增量 on_bar 两种接口，回测与实盘逻辑严格一致；回测引擎无未来函数，支持佣金、滑点等成本模型，输出夏普、索提诺、最大回撤、胜率、盈亏比等指标及逐笔交易记录，并导出 Markdown 报告与 CSV；纸面模拟与回测逐点一致，附 vnpy/CTP 实盘适配参考。命令行可一键生成数据、回测与模拟交易，101 个 pytest 用例全部通过，适合策略研究、教学与二次开发。
